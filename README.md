# 🩺 AI Health Assistant

## Problem Statement

Many people cannot easily access early cardiovascular risk assessment.
This project provides an AI-powered health assistant that predicts heart disease risk
using patient health parameters and provides explainable recommendations.

## Solution

AI Health Assistant uses Machine Learning to analyze patient information and predict
cardiovascular risk.

Features:
- Heart disease prediction
- AI confidence score
- Health safety score
- Explainable AI factors
- Risk visualization dashboard
- Patient history database
- PDF health report generation


## AI Technology Used

- Python
- Flask
- Random Forest Classifier
- Explainable AI using Feature Importance
- SQLite Database


## Tech Stack

Frontend:
- HTML
- CSS
- Bootstrap

Backend:
- Flask

Database:
- SQLite

Machine Learning:
- Scikit-learn


## How to Run Locally

Install requirements:

pip install -r requirements.txt


Run:

python app.py


Open:

http://127.0.0.1:5000
